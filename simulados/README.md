# Simulados

Minhas soluções dos [simulados de live coding](../docs/SIMULADO-LIVE-CODING.md), uma pasta por tentativa:

```
simulados/
├── rodada-1-2026-10-21/
├── rodada-1-2026-10-23/   # 2ª tentativa: comparar com a primeira
└── rodada-3-2026-10-25/
```

Não apague as tentativas antigas: comparar uma com a outra mostra a evolução. A nota de cada tentativa vai para a
tabela "Histórico dos simulados" no fim do arquivo do simulado.
